# Shortcuts

| Shortcut | Action | Where |
| --- | --- | --- |
| `Ctrl+S` | Save the scene, or save the prefab | Global, in Edit |
| `Ctrl+Shift+S` | Save scene as | Global |
| `Ctrl+B` | Open the build dialog | Global |
| `W` `E` `R` | Move, rotate, scale | Scene View, focused |
| Right button + WASD | Fly the camera | Scene View |
| Right button + Q / E | Down / up | Scene View |
| Shift while moving | Speed ×3 | Scene View |
| Wheel | Zoom | Scene View |
| `F2` | Rename | Content Browser |
| `Del` | Delete object | Hierarchy |
| `Del` | Delete file | Content Browser |

`W`, `E`, and `R` do not change the gizmo while an Inspector `InputText` has focus. The editor camera does not move unless you hold the right mouse button.

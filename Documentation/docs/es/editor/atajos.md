# Atajos

| Atajo | Acción | Dónde |
| --- | --- | --- |
| `Ctrl+S` | Guardar escena, o guardar prefab | Global, en Edit |
| `Ctrl+Shift+S` | Guardar escena como | Global |
| `Ctrl+B` | Abrir el diálogo de build | Global |
| `W` `E` `R` | Mover, rotar, escalar | Scene View con foco |
| Botón derecho + WASD | Volar la cámara | Scene View |
| Botón derecho + Q / E | Bajar / subir | Scene View |
| Shift mientras te mueves | Velocidad ×3 | Scene View |
| Rueda | Zoom | Scene View |
| `F2` | Renombrar | Content Browser |
| `Supr` | Borrar objeto | Jerarquía |
| `Supr` | Borrar archivo | Content Browser |

`W`, `E` y `R` no cambian el gizmo si el foco está en un `InputText` del Inspector. La cámara del editor tampoco se mueve si no mantienes el botón derecho.
